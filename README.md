## Featured project

### [Multi-Location Operations Performance](https://github.com/dontrellkelly-lab/operations-performance-analytics)

A working Python and SQL prototype that checks daily reports from **250 fictional locations**, separates invalid records, and produces location scorecards, regional summaries, and an executive brief.

**Business question:** Which locations need management attention, and where should reporting problems be resolved before drawing conclusions?

- Validates 44,772 synthetic source rows across a 180-day reporting period.
- Flags missing reports, duplicate records, and inconsistent values.
- Calculates weighted service and productivity measures with reporting-coverage context.
- Includes reproducible code, SQL, seven automated behavior tests, and documented limitations.

[Read the executive brief](https://github.com/dontrellkelly-lab/operations-performance-analytics/blob/main/outputs/executive_brief.md) · [Explore the code](https://github.com/dontrellkelly-lab/operations-performance-analytics/tree/main/src) · [See the metric definitions](https://github.com/dontrellkelly-lab/operations-performance-analytics/blob/main/docs/data-dictionary.md)

**Status:** Initial analytical prototype. An interactive dashboard and further analysis are planned. All data is synthetic; the project README documents the AI-assisted initial implementation and review process.
